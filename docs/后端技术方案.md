# 智慧交通项目 —— 后端技术方案

| 项目信息 | 内容 |
| --- | --- |
| 配套前端 | HarmonyOS ArkTS 应用（`com.example.smarttransportation`） |
| 推荐技术栈 | **Spring Boot 3.2 + MyBatis-Plus 3.5 + MySQL 8.0 + Redis 7（可选）** |
| 运行环境 | JDK 17 + Maven 3.9 |
| 接口风格 | RESTful + JSON，统一前缀 `/api/v1` |
| 文档版本 | V1.0 |

> 配套文档：`docs/项目设计文档.md`（总体设计）、本文件（服务端详细方案）。

---

## 1. 结论速览

**默认选型：Spring Boot 3 + MySQL 8**，理由：

1. **答辩友好**：Java 后端是计算机毕设最主流形态，评委熟悉度高，分层架构（Controller / Service / Mapper / Entity）可直接画进论文架构图。
2. **工程规范**：Bean Validation 参数校验、全局异常处理、统一响应体、事务管理、定时任务——每一条都能在论文"系统实现"章节独立成节。
3. **生态完备**：MyBatis-Plus 省掉 80% SQL；Knife4j 自动生成接口文档（答辩可现场演示）；Hutool 处理日期/加密/坐标计算。
4. **数据源可控**：拥堵指数、公交到站等无免费稳定数据源时，可在后端用"定时任务 + 仿真算法"生成，前端无感知。
5. **与前端解耦**：前端 Repository 层已经抽象，后端换语言不影响 ArkTS 代码。

**何时改用 Node.js**：如果你 Java 基础薄弱、只剩 4 周以内时间，选 `NestJS + Prisma + MySQL`（写法与 ArkTS 接近，实体定义可直接复制）。见 [第 10 章](#10-备选方案-bnodejs)。

## 4. 数据库设计（MySQL 8）

### 4.1 表清单

| --- | --- |

### 6.1 统一响应体与全局异常

```java
// common/Result.java
@Data
public class Result<T> implements Serializable {
    private int code;
    private String message;
    private T data;
    private long timestamp = System.currentTimeMillis();

    public static <T> Result<T> ok(T data) {
        Result<T> r = new Result<>();
        r.setCode(0);
        r.setMessage("success");
        r.setData(data);
        return r;
    }
    public static <T> Result<T> fail(int code, String message) {
        Result<T> r = new Result<>();
        r.setCode(code);
        r.setMessage(message);
        return r;
    }
}

// common/GlobalExceptionHandler.java
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {
    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBiz(BusinessException e) {
        return Result.fail(e.getCode(), e.getMessage());
    }
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValid(MethodArgumentNotValidException e) {
        String msg = e.getBindingResult().getFieldError() == null ? "参数错误"
                : e.getBindingResult().getFieldError().getDefaultMessage();
        return Result.fail(400, msg);
    }
    @ExceptionHandler(Exception.class)
    public Result<Void> handleEx(Exception e) {
        log.error("server error", e);
        return Result.fail(500, "服务异常");
    }
}
```

### 6.3 Service + MyBatis-Plus

```java
@Service
@RequiredArgsConstructor
public class BusServiceImpl implements BusService {
    private final BusLineMapper lineMapper;
    private final LineStationMapper lineStationMapper;
    private final BusArrivalMapper arrivalMapper;

    @Override
    public BusLineVO lineDetail(String lineId, int direction) {
        BusLine line = lineMapper.selectOne(
            new LambdaQueryWrapper<BusLine>().eq(BusLine::getLineId, lineId));
        if (line == null) throw new BusinessException(404, "线路不存在");

        List<LineStation> ls = lineStationMapper.selectList(
            new LambdaQueryWrapper<LineStation>()
                .eq(LineStation::getLineId, lineId)
                .eq(LineStation::getDirection, direction)
                .orderByAsc(LineStation::getStationOrder));

        BusLineVO vo = new BusLineVO();
        BeanUtils.copyProperties(line, vo);
        vo.setStations(buildStations(ls));   // 关联站点名称与坐标
        return vo;
    }
}
```

### 6.5 A* 路径规划（核心算法，论文可重点写）

```java
// util/AStarUtil.java
public class AStarUtil {
    public static List<String> search(Map<String, RoadNode> nodes,
                                      Map<String, List<RoadEdge>> adj,
                                      String start, String end, Strategy strategy) {
        PriorityQueue<NodeState> open = new PriorityQueue<>(Comparator.comparingDouble(s -> s.f));
        Map<String, Double> gScore = new HashMap<>();
        Map<String, String> cameFrom = new HashMap<>();
        gScore.put(start, 0.0);
        open.add(new NodeState(start, 0.0, h(nodes.get(start), nodes.get(end))));

        while (!open.isEmpty()) {
            NodeState cur = open.poll();
            if (cur.id.equals(end)) return rebuild(cameFrom, end);
            for (RoadEdge e : adj.getOrDefault(cur.id, List.of())) {
                double cost = weight(e, strategy);          // FASTEST: 时长 / SHORTEST: 距离 / AVOID: 拥堵加权
                double tentative = gScore.getOrDefault(cur.id, Double.MAX_VALUE) + cost;
                if (tentative < gScore.getOrDefault(e.getToNode(), Double.MAX_VALUE)) {
                    cameFrom.put(e.getToNode(), cur.id);
                    gScore.put(e.getToNode(), tentative);
                    open.add(new NodeState(e.getToNode(), tentative,
                             h(nodes.get(e.getToNode()), nodes.get(end))));
                }
            }
        }
        return List.of();
    }

    private static double h(RoadNode a, RoadNode b) {   // 启发函数：Haversine 距离 / 自由流速度
        return GeoUtil.haversine(a.getLatitude(), a.getLongitude(), b.getLatitude(), b.getLongitude()) / 40.0;
    }
}
```

**亮点**：三种策略只需改变 `weight()` 计算方式；拥堵权重来自 `traffic_segment` 表实时更新，体现"动态路径规划"，比直接调用高德 API 更有论文价值。

### 6.6 拥堵指数仿真（解决无真实数据源问题）

```java
// task/TrafficSimulateTask.java —— 每 60 秒刷新一次
@Scheduled(fixedRate = 60_000)
public void refreshCongestion() {
    int hour = LocalTime.now().getHour();
    double peak = peakFactor(hour);          // 早高峰 7-9、晚高峰 17-19 抬高
    for (TrafficSegment seg : segmentMapper.selectList(null)) {
        double rand = ThreadLocalRandom.current().nextDouble(-0.8, 0.8);
        double index = Math.max(0, Math.min(10, peak * 6 + rand));
        seg.setCongestionLevel(LevelUtil.of(index));
        seg.setAvgSpeed((int) (seg.getFreeSpeed() * (1 - index / 15.0)));
        segmentMapper.updateById(seg);
    }
    redisTemplate.delete("traffic:index:*");  // 失效缓存
}

private double peakFactor(int hour) {
    double morning = Math.exp(-Math.pow(hour - 8, 2) / 4.0);
    double evening = Math.exp(-Math.pow(hour - 18, 2) / 4.0);
    return 0.35 + morning + evening;          // 0.35 基础值
}
```

同理，`bus_arrival` 可按 `interval_min` 与站间平均时长仿真车辆位置。

| 方案 | 说明 | 适用 |

## 8. 联调与部署

### 8.1 局域网联调（最重要，毕设演示用）

1. 后端 `application.yml` 设置 `server.address=0.0.0.0`，端口 `8080`；
2. 查询宿主机局域网 IP：`ipconfig` → 例如 `192.168.1.23`；
3. 鸿蒙端 `ApiConstants.BASE_URL = 'http://192.168.1.23:8080/api/v1'`；
4. **必须放开明文 HTTP**——HarmonyOS 默认禁止 cleartext，在 `entry/src/main/module.json5` 增加：

```json5
"networkSecurityConfig": {
  "baseConfig": { "cleartextTrafficPermitted": false },
  "domain": [
    { "name": "192.168.1.23", "subdomains": true, "cleartextTrafficPermitted": true }
  ]
}
```

5. 模拟器访问宿主机用 `10.0.2.2`；真机必须与电脑在同一 WiFi，且防火墙放行 8080 端口。

> 常见误区：鸿蒙 App 的网络请求**不是浏览器**，不存在 CORS 跨域问题，后端无需配置 `@CrossOrigin`（只为 H5 调试可配）。

## 10. 备选方案 B：Node.js

若不用 Java，推荐 `NestJS + Prisma + MySQL` 或更轻的 `Express + Sequelize`：

```ts
// route/plan 示例（Express）
app.get('/api/v1/route/plan', async (req, res) => {
  const { origin, destination, mode = 'DRIVE', strategy = 'FASTEST' } = req.query as any;
  const plans = await routeService.plan(origin, destination, mode, strategy);
  res.json({ code: 0, message: 'success', data: plans, timestamp: Date.now() });
});
```

优势：实体定义（TS interface）可与鸿蒙端 `model/*.ets` **直接复用**；启动快、依赖少。
劣势：论文中"分层架构""事务管理"等表述不如 Java 体系厚重。

**选型判据**：Java 能写 → 选 Spring Boot；只会前端 TS → 选 NestJS/Express；要做预测算法 → Python 侧单独做一个算法服务，主服务仍用 Spring Boot。

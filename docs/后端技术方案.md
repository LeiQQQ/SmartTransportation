# 智慧交通项目 —— 后端技术方案（V2 · 信号配时方向）

| 项目信息 | 内容 |
| --- | --- |
| 配套前端 | HarmonyOS ArkTS 手机应用（`com.example.smarttransportation`） |
| 服务对象 | 西安城墙内片区 15 个信号路口、18 条路段 |
| 推荐技术栈 | **Spring Boot 3.2 + MyBatis-Plus 3.5 + MySQL 8.0 + Redis（可选）** |
| 运行环境 | JDK 17 + Maven 3.9 + MySQL 8.0 |
| 接口前缀 | `/api/v1` |
| 文档版本 | V2.0 |

---

## 1. 后端职责边界

| 职责 | 说明 |
| --- | --- |
| 路网数据服务 | 提供路口、进口道、路段信息 |
| 配时优化引擎 | Webster 模型计算周期与绿信比，输出相位方案 |
| 交通流仿真 | 按时间生成各进口道流量、排队、延误 |
| 指标评价 | 计算优化前后延误/排队/通行量/停车次数及改善率 |
| 事件服务 | 交通事件增删查 |
| 数据落库 | 历史流量与配时方案留痕，支持回溯对比 |

**不做**：真实信号机对接（公安交管封闭系统，个人无法接入）、用户体系（本期手机端无登录）。

## 6. 核心算法实现

### 6.1 Webster 最优周期

```java
// algo/WebsterCalculator.java
public final class WebsterCalculator {
    private static final int MIN_CYCLE = 60;
    private static final int MAX_CYCLE = 150;

    /**
     * @param flows  各相位关键流量（辆/h）
     * @param caps   各相位通行能力（辆/h）
     * @param lostTime 总损失时间
     */
    public static PlanResult calculate(double[] flows, double[] caps, int lostTime) {
        int n = flows.length;
        double[] y = new double[n];
        double sumY = 0;
        for (int i = 0; i < n; i++) {
            y[i] = Math.min(0.95, flows[i] / Math.max(1, caps[i]));
            sumY += y[i];
        }
        if (sumY >= 0.92) sumY = 0.92;          // 过饱和保护

        int cycle = (int) Math.round((1.5 * lostTime + 5) / (1 - sumY));
        cycle = Math.max(MIN_CYCLE, Math.min(MAX_CYCLE, cycle));

        int effective = cycle - lostTime;
        int[] greens = new int[n];
        for (int i = 0; i < n; i++) {
            greens[i] = Math.max(8, (int) Math.round(effective * y[i] / sumY));
        }
        return new PlanResult(cycle, greens, lostTime);
    }
}
```

### 6.2 Webster 延误

```java
// algo/DelayCalculator.java
public static double webster(int cycle, double greenRatio, double saturation, double volumePerHour) {
    double x = Math.min(0.95, saturation);
    double q = Math.max(0.05, volumePerHour / 3600.0);
    double uniform = cycle * Math.pow(1 - greenRatio, 2) / (2 * (1 - greenRatio * x));
    double random = Math.pow(x, 2) / (2 * q * (1 - x));
    return uniform + random;
}
```

### 6.3 流量仿真

```java
// algo/FlowSimulator.java
/** 高斯双峰：早 8 点、晚 18 点 */
private static double peakFactor(double hour) {
    double morning = Math.exp(-Math.pow(hour - 8, 2) / 4);
    double evening = Math.exp(-Math.pow(hour - 18, 2) / 4);
    return 0.35 + morning + evening;
}

public static int simulateVolume(int baseFlow, String code, String dir, double hour) {
    double noise = 1 + (ThreadLocalRandom.current().nextDouble(-0.12, 0.12));
    double stable = 0.8 + 0.4 * Math.abs((code + dir).hashCode() % 100) / 100.0;
    return (int) Math.round(baseFlow * stable * peakFactor(hour) * noise);
}
```

### 7.2 鸿蒙端联调（必须配置）

1. `AppConstants.BASE_URL` 改为宿主机局域网 IP（模拟器用 `10.0.2.2`）；
2. `AppConstants.USE_REMOTE = true`；
3. **明文 HTTP 放行**（HarmonyOS 默认禁止，否则请求直接失败）：

```json5
// entry/src/main/module.json5 的 module 节点下
"networkSecurityConfig": {
  "baseConfig": { "cleartextTrafficPermitted": false },
  "domain": [
    { "name": "192.168.1.23", "subdomains": true, "cleartextTrafficPermitted": true }
  ]
}
```

### 7.3 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 请求超时 | 手机与电脑不同网段 | 同一 WiFi，关闭电脑防火墙对应端口 |
| `2300007` 类错误 | 明文 HTTP 被拦截 | 配置 `networkSecurityConfig` |
| 真机访问 `localhost` 失败 | 手机端 localhost 是手机自己 | 改局域网 IP |
| 跨域疑虑 | 鸿蒙 App 非浏览器，无 CORS | 无需配置跨域 |

## 9. 备选：不写后端

若不使用 Spring Boot，可保留 `MockTrafficRepository`（已实现），把 Webster 算法直接放在 ArkTS 端计算——当前 `XianWallMock.getSignalPlan()` 已在端侧实现同样逻辑。这种"纯端侧仿真"方案足以支撑答辩演示，代价是论文中"服务端设计"章节较弱。

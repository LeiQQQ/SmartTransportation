## 1. 项目定位

### 1.1 一句话定位

> 面向西安城墙内片区，构建一套 **"感知 → 优化 → 评价 → 服务"** 的交通信号配时闭环系统：后端通过 Webster 模型与交通流仿真动态优化路口配时，鸿蒙端将优化过程与结果以可视化方式呈现，并把算法结论翻译为用户可理解的信息（如"该方向还需等待 26 秒"）。

### 1.2 属于智慧交通的哪个子系统

| ITS 子系统 | 本项目覆盖 |
| --- | --- |
| ATMS（先进交通管理系统） | 信号配时优化、路段拥堵评估（核心） |
| ATIS（先进出行者信息系统） | 路段态势发布、事件提示、路口等待时间 |
| APTS（公共交通） | 不做 |
| AVCS / ETC | 不做 |

### 1.3 三个立得住的创新点

| # | 创新点 | 为什么算创新 |
| --- | --- | --- |
| 1 | **流量自适应的配时优化闭环** | 按 5 分钟粒度的进口道流量重算周期与绿信比，而非固定配时；优化前后指标可量化对比 |
| 2 | **算法结果的用户化表达** | 把"周期 96s / 绿信比 34:15:20:12"翻译成"你还要等 26 秒"，解决管理端算法在用户端无感知的问题 |
| 3 | **双渲染引擎的路网可视化** | Canvas 拓扑图（保底）与 Petal Maps 真实底图（增强）共用一套覆盖物模型，弱环境可降级 |

## 7. 功能模块设计

### M1 首页·态势总览

- 拥堵指数：片区加权平均，0~10，五级色阶。
- 路网缩略图：`TopologyRenderer` 精简版，仅画节点与连边，不可交互。
- 拥堵 TOP3：按 `saturation` 降序，点击直达路口详情。
- 成效提示条：滚动显示"当前片区平均延误较固定配时下降 21.4%"。

### M2 片区路况图

- 手势：`PinchGesture` 缩放 0.8×~3×，`PanGesture` 平移，双击复位。
- 节点着色：饱和度 `v/c` → 五级色。
- 连线宽度 = 车道数映射（1~3 车道 → 2/3/4 vp）。
- 点击节点：放大 + 涟漪动画 → Navigation 跳转详情。
- 自动刷新：5s 拉取最新 `FlowRecord`，颜色 300ms 过渡，避免闪烁。

### M3 路口实时状态（核心页）

- Canvas 绘制十字路口俯视图：四条进口道矩形 + 排队车辆方块。
- 相位驱动车流：绿灯相位对应的进口道车辆沿车道方向平移消散，红灯相位持续累积排队。
- 倒计时环：`剩余绿灯 / 相位绿灯时长`，最后 3s 变橙。
- 用户化表达：「东进口 预计等待 26 秒 · 排队 9 辆 · 约 2 个周期可通过」。
- 数据刷新：状态 5s 拉取，倒计时本地每秒递减。

### M4 信号配时看板

- 甘特图：一个周期内 4 个相位横向堆叠（绿/黄/全红三段色）。
- 指标卡：周期时长、总损失时间、各相位绿信比。
- 优化对比：延误 / 排队 / 通行量 / 停车次数 四项条形对比 + 改善百分比。
- 时段切换：早高峰 / 平峰 / 晚高峰三套方案对比。

### M5 事件中心

- 列表：类型标签、路段名、时间、影响范围。
- 筛选：`Tabs` 或 `Segment` 按类型过滤。
- 上报：类型选择 + 自动定位填充坐标 + 描述，提交后本地入库，联网时上传。

### M6 我的

- 收藏路口（`preferences` 存储）、常看路口排序。
- 深色模式开关、缓存清理、离线数据说明。
- 关于页链接到 M7 数据说明。

### M7 数据说明

- 说明数据来源：**仿真生成 + 公开路网资料**。
- 说明指标口径：饱和度、延误、绿信比的公式与单位。
- 目的：答辩时主动交代，避免被质疑数据真实性。

## 9. 花瓣地图接入方案

### 9.1 三条路径对比

| 路径 | 能力 | 门槛 | 本项目定位 |
| --- | --- | --- | --- |
| **A. Map Kit SDK**（`@kit.MapKit`） | 可交互地图、标记、覆盖物、相机控制 | AGC 建项目 + 开通 Map Kit + `client_id` + **签名证书 SHA256 指纹** + 真机 | 增强模式（`MAP_MODE='MAP_KIT'`） |
| **B. Petal Maps REST API** | 静态地图图片、路径规划、POI、地理编码 | 仅需 API Key | 备选（静态底图） |
| **C. Canvas 拓扑图** | 完全可控、零依赖 | 无 | **默认模式** |

### 9.2 关键事实

1. **Petal Maps 不是开源产品**，是"免费额度 + 商业授权"的开放平台（<https://developer.petalmaps.com/>）。
2. **国内数据精细度弱于高德/百度**，POI 与实时路况不足。但本项目只需要**底图与路网轮廓**，不依赖其交通数据，因此完全够用。
3. **Map Kit 在模拟器上支持有限**，正常需真机 + 正式签名证书。答辩若用模拟器，走 Canvas 拓扑图更稳。
4. 本项目要在图上叠加信号相位、排队车辆、倒计时等元素，**拓扑图比真实底图更清晰**，这也是默认选 Canvas 的实质理由。

### 9.3 双渲染引擎设计

  static readonly REFRESH_FLOW_MS: number = 5000;

`TopologyRenderer` 与 `MapKitRenderer` 实现同一接口，页面只依赖接口，切换只改 `AppConstants.MAP_MODE`。

### 9.4 Map Kit 接入步骤（若要启用）

1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html) → 创建项目 → 添加 HarmonyOS 应用（包名 `com.example.smarttransportation`）。
2. 「项目设置 → 常规」获取 **Client ID**；「API 管理」开通 **Map Kit**。
3. 配置发布证书指纹：`keytool -list -v -keystore xxx.p12` 取 SHA256，填入 AGC。
4. `module.json5` 的 `module` 下添加：

```json5
"metadata": [
  { "name": "client_id", "value": "<你的 Client ID>" }
]
```

5. 页面使用组件：

```ts

@Entry
@Component

  private mapOptions: mapCommon.MapOptions = {
    position: { target: { latitude: 34.2606, longitude: 108.9470 }, zoom: 14 }
  };
  private callback: AsyncCallback<map.MapComponentController> =
    (err: BusinessError, controller: map.MapComponentController) => {
      if (!err) {
        const marker: mapCommon.MarkerOptions = {
          position: { latitude: 34.2606, longitude: 108.9470 },
          title: '钟楼'
        };
        controller.addMarker(marker);
      }
    };

  build() {
    MapComponent({ mapOptions: this.mapOptions, mapCallback: this.callback })
      .width('100%').height('100%')
  }

```

> **降级策略**：`MapKitRenderer` 初始化失败（无 `client_id`、无网络、模拟器不支持）时，捕获异常并自动回退到 `TopologyRenderer`，页面顶部提示"已切换为拓扑模式"。**保证任何环境下都能演示。**

## 10. 核心算法

### 10.1 饱和度与分级

```
saturation = volume / capacity
capacity   = saturationFlow × (green / cycle) × lanes
```

| 饱和度 v/c | 等级 | 颜色 |
| --- | --- | --- |
| < 0.4 | 畅通 | `#00C48C` |
| 0.4 ~ 0.6 | 基本畅通 | `#7ED321` |
| 0.6 ~ 0.75 | 轻度拥堵 | `#FFB020` |
| 0.75 ~ 0.9 | 中度拥堵 | `#FF7A45` |
| ≥ 0.9 | 严重拥堵 | `#FF3B30` |

### 10.2 Webster 最优周期

```
y_i = q_i / s_i                     （第 i 相位流量比）
Y   = Σ y_i                         （总流量比）
L   = Σ(黄灯 + 全红 + 启动损失)       （总损失时间）
C₀  = (1.5L + 5) / (1 - Y)          （最优周期，s）
g_i = (C₀ - L) × (y_i / Y)          （第 i 相位有效绿灯）
```

约束：`C₀` 限制在 `[60, 150]` 秒；`g_i ≥ 最小绿灯 10s`；超出时按比例再分配。

### 10.3 Webster 延误模型

```
d = C(1-λ)² / [2(1-λx)] + x² / [2q(1-x)]
λ = g/C（绿信比）, x = 饱和度, q = 流量（辆/s）
```

第一项为均匀延误，第二项为随机到达附加延误。

### 10.4 流量仿真

- **时段曲线**：高斯双峰，早高峰 8:00、晚高峰 18:00，`f(t) = 0.35 + exp(-(h-8)²/4) + exp(-(h-18)²/4)`。
- **随机扰动**：泊松噪声，避免曲线过于平滑。
- **排队演化**：`queue(t+1) = max(0, queue(t) + arrival - departure)`，`departure = 绿灯时饱和流率`。
- **评价输出**：优化前后各跑 30 分钟仿真，输出 `Metrics` 与改善百分比。

## 14. 风险与对策

| 风险 | 对策 |
| --- | --- |
| Map Kit 资质批不下来 | 默认 Canvas 拓扑图，Map Kit 仅作可选增强，失败自动回退 |

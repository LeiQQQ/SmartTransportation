## 4. 算法口径核对（重要）

代码中的真实公式与参数，答辩口径以此为准。

| 项 | 文档原描述 | 代码实现 | 结论 |
| --- | --- | --- | --- |
| 流量生成 | 高斯双峰 + 泊松噪声 | `base = 480 + pseudo(id,dir) × 420`（480~900 辆/h），再乘 `peakFactor`；扰动为**确定性哈希伪随机**（`h×31+c % 9973`），非泊松 | 🔶 无随机噪声，同一时刻刷新结果稳定 |
| 时段曲线 | `f(t)=0.35+exp(-(h-8)²/4)+exp(-(h-18)²/4)` | 与文档一致 | ✅ |
| 通行能力（展示用饱和度） | `saturationFlow × (g/C) × lanes` | `capacityOf(1650, lanes, 0.48)`，绿信比**固定 0.48** | 🔶 与当前配时方案不自洽 |
| 排队长度 | 排队演化模型 | `queue = round(sat² × 14)` | 🔶 经验拟合，非演化推演 |
| 平均延误（列表展示） | Webster 延误模型 | `delay = round(sat × 45 + 6)` | 🔶 线性拟合，与 Webster 模型输出不同源 |
| 片区拥堵指数 | 加权平均 | `index = avg(所有进口道饱和度) × 10`，上限 10；`avgSpeed = 45×(1-avg/1.6)` | 🔶 为**等权平均**，文档写的是"加权" |
| 关键相位流量比 | 未说明取值方式 | `qEW = max(东,西进口流量)`，`yEW = qEW/(1650×lanes)` | ✅ 符合关键相位定义（取相位内最大值） |
| 左转相位 | 独立流量比 | `y左转 = 0.3 × y直行` | 🔶 折算系数，非独立采集 |
| 总流量比上限 | 未说明 | `Y = min(0.92, Σy)` | ✅ 过饱和保护 |
| 损失时间 | `L = Σ(黄灯+全红+启动损失)` | `lostTime = 16` 常量，等价于 `4 相位 ×(黄 3 + 全红 1)` | 🔶 未单独计入启动损失 |
| 最优周期 | `C₀=(1.5L+5)/(1-Y)` | 一致，`clamp[60,150]` | ✅ |
| 绿灯分配 | `g_i=(C₀-L)×(y_i/Y)` | 一致；下行 `max(10,…)`，左转 `max(8,…)` | 🔶 文档写"最小绿灯 10s"，实际左转为 8s |
| 延误模型（评价用） | Webster 两项式 | 一致，`x≤0.95`、`q≥0.05` 截断 | ✅ |
| 评价 · 优化前基线 | 真实固定配时对比 | 硬编码 `C=120`、`λ=0.42` | 🔶 构造基线 |
| 评价 · 通行量 | 仿真统计 | `before=0.93V`、`after=V`（恒改善 7.5%） | 🔶 构造值 |
| 评价 · 停车次数 | 仿真统计 | `before=1.6x`、`after=1.2x`（恒改善 25%） | 🔶 构造值 |
| 时段切换 | 早/平/晚三套方案 | `scenario` 仅透传到返回字段，**不参与任何计算**；流量由系统当前时间决定 | 🔶 切换只改标题 |
| 首页成效提示条 | 实时计算 | 硬编码文案「下降 21.4%」 | 🔶 静态文案 |

> **结论**：算法主链路（Webster 周期 + 绿信比分配 + Webster 延误）真实可算；**评价模块的通行量、停车次数、优化前基线为构造值**，只能在论文/答辩中表述为「演示性估算」，不能称为仿真统计结果。
